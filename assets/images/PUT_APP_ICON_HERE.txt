Положи сюда иконку приложения:

app_icon.png — 1024×1024 пикселей, PNG

Рекомендации:
- Фон: глубокий teal (#0F766E) или минималистичный символ
- Без прозрачности для App Store
- Простой символ: лист / дыхание / галочка / буква P

После добавления файла выполни:
  dart run flutter_launcher_icons
  dart run flutter_native_splash:create

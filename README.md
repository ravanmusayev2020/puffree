# Puffree

Минималистичное приложение для отказа от курения.

## Как запустить

1. Открой папку `puffree` в Android Studio / VS Code / Cursor
2. Выполни:
```bash
flutter pub get
flutter gen-l10n
flutter run
```

## Основные экраны

- **Splash** → онбординг или главная
- **Онбординг** — сбор данных о привычке
- **Главная** — уровень, стрик, мотивация, чек-ин
- **Задания** — ежедневные миссии
- **Premium** — 3 дня бесплатно + покупка
- **Прогресс** — статистика + восстановление тела
- **Настройки** — сброс, язык, дисклеймер

## Архитектура

- **BLoC** — ProgressBloc, DailyBloc, PremiumBloc
- **Хранение** — SharedPreferences
- **Дизайн** — минимализм, Google Fonts (Inter), Iconsax
- **Локализация** — 14 языков (en + ru полностью, остальные заготовки)

## Premium

- Пробный период: 3 дня (один раз)
- Готово к подключению RevenueCat (`purchases_flutter`)

## Важно

Приложение мотивационное. Не является медицинским средством.
